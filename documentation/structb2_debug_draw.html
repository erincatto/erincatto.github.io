Detailed Description

This struct holds callbacks you can implement to draw a Box2D world.

Callbacks receive world coordinates. In large world mode the translation is double precision so it stays accurate far from the origin. Shift into your own camera frame inside the callbacks. Initialize with b2DefaultDebugDraw.
