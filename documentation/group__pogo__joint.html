struct b2PogoJointDef

Pogo joint definition.

Data Fields
b2JointDef base Base joint definition.
float dampingRatio The spring damping ratio, non-dimensional.
float hertz The spring stiffness Hertz, cycles per second.
float impulse The initial pogo internal impulse.

The pogo is typically recreated every frame. This gives a way to move the internal state forward for smoother spring behavior.

int internalValue Used internally to detect a valid definition. DO NOT SET.
float maxCompressionForce Maximum compression force. How hard the pogo pushes the mover up from the ground.
float maxTensionForce Maximum tension force. Controls how sticky the mover is to ground.
b2Vec2 normal Normal vector at the contact.
float restLength Spring length.
float velocity The initial pogo internal velocity.

The pogo is typically recreated every frame. This gives a way to move the internal state forward for smoother spring behavior.
