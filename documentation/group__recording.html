◆ b2Recording

typedef struct b2Recording b2Recording

Opaque handle for a recording buffer.

Create one, hand it to b2World_StartRecording, then save its bytes and destroy it. The buffer grows as the world records into it.

◆ b2CreateRecording()

b2Recording * b2CreateRecording ( int byteCapacity)

Create a recording buffer.

The buffer grows on demand. byteCapacity pre-sizes it to avoid reallocations during a known-length session. Pass 0 for a small default.

Returns
A recording handle, freed with b2DestroyRecording

◆ b2World_StartRecording()

void b2World_StartRecording ( b2WorldId worldId,
b2Recording * recording )

Begin recording the world into recording.

Serializes a snapshot of the current world as the seed, then logs every mutating call. Call at a step boundary, before or after creating bodies. Start before the first step to capture the whole session. No effect if already recording or if the world is locked.

Parameters
worldIdThe world to record
recordingA recording buffer from b2CreateRecording
