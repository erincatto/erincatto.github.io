Math Tricks

Distance between rotations

If you want the distance between two rotations you could compute the relative rotation like this:

$$R = R_1^T * R_2$$

Then you can extract the axis and angle. Usually this is done with quaternions.

$$q = q_1^* q_2$$

Where \(^*\) is the conjugate. The length of the vector part is:

$$a = \sqrt{ q_v \cdot q_v }$$

Then you can get the angle:

$$\theta = 2 * \operatorname{atan2}(a, q_s)$$

But this required an expensive square root and arctangent.

A standard trick for finding the distance between two unit vectors is to take the dot product of them. This is equal to the cosine of the angle between them. The angle will between the vectors gets smaller as the dot product approaches one. For example, you can determine if the angle between two unit vectors is less than an angle \(\phi\) using this test:

$$n_1 \cdot n_2 > \cos{\phi}$$

Typically \(\phi\) is a constant like 5 degrees. You can compute this cosine offline and use the constant:

$$n_1 \cdot n_2 > 0.9962$$

Wouldn’t it be nice if we can use the same trick for quaternions? Well we can!

The relative quaternion has a vector component and scalar component expressed as:

$$q = \sin(\theta / 2) q_v + \cos(\theta / 2)$$

Notice the scalar part is \(\cos(\theta / 2)\). If we can find the scalar part efficiently, we can use this test to determine the size of the relative rotation.

$$q_s > \cos(\phi / 2)$$

It turns out the quaternion multiplication gives us the scalar result efficiently:

$$q_s = q_{1v} \cdot q_{2v} + q_{1s} q_{2s}$$

Or we can use the simple test:

$$q_1 \cdot q_2 > \cos(\phi / 2)$$

This is just the four component quaternion dot product. This is similar to the unit vector case and cheap to compute. No square root or arctangent is needed.

However, I left one crucial detail out. Quaternions have double cover, so \(q\) and \(-q\) are the same rotation. The quaternion dot product can be close to negative one and be a small angle. So use this test instead:

$$(q_1 \cdot q_2)^2 > \cos(\phi / 2)^2$$
